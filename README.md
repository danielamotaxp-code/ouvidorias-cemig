# Ouvidorias Cemig

Site para gerar, enviar e registrar as ouvidorias da Cemig (Wisecoop · Watt Wise).

- Site: https://danielamotaxp-code.github.io/ouvidorias-cemig/
- Registros: repositório privado `ouvidorias-cemig-dados`
- `config.js` guarda a chave de acesso ao repositório de dados, criptografada com a senha de acesso.
